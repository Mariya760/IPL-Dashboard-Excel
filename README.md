# 🏏 IPL Performance Analysis Dashboard

## 📌 Project Overview

This project is an interactive IPL Performance Analysis Dashboard developed using Microsoft Excel. It analyzes IPL match data to understand team performance, player statistics, match outcomes, and seasonal trends.

## 🎯 Objective

- Analyze team performance across IPL seasons
- Identify top-performing players
- Analyze match outcomes and winning patterns
- Compare team performance across different seasons
- Generate meaningful insights from IPL data

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Excel Charts

## 🧹 Data Cleaning & Transformation

The raw IPL dataset was cleaned and transformed using Power Query.

- Removed duplicate records
- Handled missing values
- Corrected data types
- Standardized team and player names
- Prepared the data for analysis

## 📊 Dashboard Features

- Team-wise performance analysis
- Player statistics
- Season-wise performance
- Match outcome analysis
- Toss analysis
- Interactive filters and charts

## 🔍 Key Findings

- Identified teams with the highest number of wins
- Identified top-performing players
- Compared team performance across IPL seasons
- Analyzed match-winning and toss-winning patterns
- Identified important trends in IPL match results
